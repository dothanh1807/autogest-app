AutoGest Tiếng Việt

Let your phone repeat the boring taps

AutoGest is an Android app that runs automation scripts you build or record yourself: taps, swipes, typing, opening apps — replayed with a natural, human-like rhythm.

What you can do

Build scripts step by step Tap, long press, swipe, scroll, type text, wait, press Back / Home / Recent apps, or open an app. Pick each point right on the screen.
Record instead of typing Do the task once while recording, review the captured steps, keep the ones you want.
React to what is on screen Tap an image when it appears, wait for a color, or run “If … then” and “Repeat until” blocks.
Run on your terms Start from the app, a home-screen shortcut or a schedule; pause and stop from the floating bubble or the notification.
Share scripts Export a script as an .autoscript file and import scripts others send you.

Privacy

The app has no Internet permission, no accounts, no ads and no analytics. The Accessibility service is used only to run the scripts you start, and everything you create stays on your phone.
